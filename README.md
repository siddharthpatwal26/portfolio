# Siddharth Patwal | Portfolio

**Live site: https://siddharthpatwal26.github.io/portfolio/**

Personal portfolio of Siddharth Patwal, an MCA graduate (G.B. Pant Institute of Engineering & Technology) looking for **Data Analyst, AI/ML, or Backend Developer** roles. Based in Roorkee, Uttarakhand, with a Delhi correspondence address.

## What's on the site

- **Focus switch:** filter the projects by Everything, Data analyst, AI / ML, or Backend.
- **Featured projects:**
  - **GraniteAgent:** agentic research assistant built on IBM Granite-3-8B and the watsonx.ai REST API (IBM SkillsBuild capstone).
  - **PlagioCheck:** full-stack plagiarism detector using TF-IDF and cosine similarity, with live web cross-checking through the Tavily API. React, Node.js/Express, MongoDB, and a Python Flask microservice.
  - **Netflix Content Analysis:** 8,793 titles analyzed with Excel, SQL, Python, and Power BI.
  - **Unemployment Analysis with Python:** state-wise unemployment trends and the economic impact of Covid-19.
- **Interactive analytics hub:** Chart.js charts for the Netflix and unemployment analyses.
- **Skills, experience, education, and certifications**, matching my resume.
- **Contact form:** messages are emailed to me through Web3Forms.
- **Resume preview** and a copy-email button.

## Built with

HTML5, CSS3, JavaScript (ES6+), Chart.js, Font Awesome, Google Fonts. Hosted on GitHub Pages.

## Run it locally

Open `index.html` in any browser, or start a local server:

```
python -m http.server 8080
```

Then visit `http://localhost:8080`.

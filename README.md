# Siddharth Patwal - Professional Portfolio Website

A modern, responsive, dark-mode portfolio built with **HTML5, CSS3, JavaScript (ES6+), and Chart.js**. Designed for **Siddharth Patwal**, Data Analyst candidate and MCA student.

---

## 🌟 Features Included

1. **Hero Section**
   - Live typing animation showcasing core skills & roles.
   - Animated statistical counter (8,793 titles analyzed, 8.2 & 8.08 CGPAs, 4 certifications).
   - Quick action CTAs (Explore Projects, Get in Touch, Copy Email, Resume Modal).

2. **Interactive Analytics Hub**
   - **Netflix Content Distribution Bar Chart** (Chart.js) – Visualizing 8,793 titles across top content-producing countries (highlighting India as #2).
   - **Unemployment Time-Series Line Chart** (Chart.js) – Highlighting urban vs. rural Covid-19 lockdown impact.

3. **Featured Projects**
   - **Netflix Content Analysis** (Excel, SQL, Python, Power BI).
   - **Unemployment Analysis with Python** (Python, Pandas, Seaborn).
   - **GraniteAgent** (IBM SkillsBuild Capstone AI Project using IBM Granite-3-8B).
   - Direct links to GitHub repositories (`github.com/Siddharthpatwal26`).

4. **Technical Skills Filtering**
   - Filterable skills grid by category (Languages, Machine Learning, Tools, Core Concepts).

5. **Experience & Education Timeline**
   - Sleek timeline featuring IBM SkillsBuild AI & Cloud Internship, MCA at G.B.P.I.E.T, and BCA at COER University.

6. **Certifications Showcase**
   - Tata (Forage) Data Visualisation, Deloitte Data Analytics, Infosys Data Science, ACS Computer Training.

7. **Contact & Resume Modal**
   - One-click email copy button with toast notification.
   - Interactive contact form.
   - Resume preview modal.

## 🚀 How to Launch Locally

### Option 1: Double Click
Simply open `index.html` directly in any web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Live Server / Python Server
From a terminal in this directory:
```bash
# Using Python
python -m http.server 8080

# Or using Node http-server
npx http-server . -p 8080
```
Then visit `http://localhost:8080`.

## 🌐 How to Deploy for Free

### GitHub Pages (Recommended)
1. Push this folder to a GitHub repository named `Siddharthpatwal26.github.io` (or `portfolio`).
2. Go to **Settings > Pages** in your repository.
3. Under **Branch**, select `main` or `master` and save.
4. Your site will be live at `https://Siddharthpatwal26.github.io/`!

### Netlify / Vercel
1. Drag and drop the project folder onto [Netlify Drop](https://app.netlify.com/drop).
2. The portfolio will instantly go live with a free custom URL!
